# Worked Examples

## 示例 1｜埃及产业地图

### 内容判断
- 主题：埃及地理、文明、产业结构、航运
- 情绪：纪录片、厚重、冷静
- 关键词：尼罗河 / 苏伊士 / 砂岩 / 工业结构 / 地缘
- 主元素：尼罗河流线
- 辅助元素：金字塔几何、苏伊士航线
- 避免：法老头像堆砌、象形文字满铺、旅游海报感

### A｜尼罗河骨架
- 粗重现代黑体
- 一条下横延展成尼罗河流线
- 石白 + 沙金 + 少量尼罗蓝
- 极轻砂岩颗粒
- SVG / AI + AE 路径动画

### B｜运河工业
- 压缩硬朗
- 航线从标题中穿过形成物流路径
- 深蓝 + 铜金
- 轻工业磨砂
- SVG + AE

### C｜文明石刻
- 宽厚碑刻感
- 局部石块切角
- 小型金字塔仅作角落平衡
- 石灰白 + 暗金
- PS / AI + AE 尘土揭示

## 示例 2｜芯片战争

- 主元素：电路线
- 字体：压缩、硬朗、精密
- 只让 1–2 条电路从字块中引出
- 黑白 + 单一警示红 / 冷青
- 动效：硬切入场 + 电路生长
- 避免：每个笔画都变成电路

## 示例 3｜黄金为什么越来越贵

- 主元素：金属切面或价格走势线
- “黄金”作为最大视觉块
- 黑金适合高级财经
- 历史叙事可切换成旧报纸 / 半调
- 避免满屏金币
