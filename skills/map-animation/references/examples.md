# Worked Examples

## 示例 1｜标出爪哇岛
- 类型：区域高亮型
- 范围：印尼群岛地图
- 重点对象：爪哇岛
- 表现：灰色底图 + 爪哇岛高亮红色 / 黄色
- 输出建议：
  1. 整体高亮版
  2. 单独爪哇岛色块透明版

## 示例 2｜太平洋、印度洋和大洋洲色块
- 类型：区域高亮型
- 范围：亚太地图 / 世界地图局部
- 重点对象：太平洋、印度洋、大洋洲
- 表现：三种不同色块清晰区分
- 输出建议：
  1. 标注版
  2. 只保留三个色块的透明版

## 示例 3｜埃及产业地图
- 类型：信息地图型
- 范围：埃及
- 信息目标：尼罗河、苏伊士运河、产业与人口结构
- 表现：底图 + 重点河流 / 运河 + 分区标签 + 信息卡
- 风格：纪录片 / 产业分析

## 示例 4｜贸易航线 / 物流流向
- 类型：路线型
- 表现：弱化底图，强化主路线
- 路线：实线主干 + 箭头方向 + 关键节点高亮
