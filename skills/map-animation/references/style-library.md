# Map Style Library

## 01｜纪录片地图 Documentary Map
- 冷静、克制、清晰
- 适合国家、历史、地缘、产业叙事

## 02｜财经信息地图 Finance Map
- 深色背景、清晰节点、路线感强
- 适合贸易流向、油气、黄金、港口、航运

## 03｜瑞士信息图地图 Swiss Infographic Map
- 极简、网格、留白、信息清楚
- 适合对比、数据、科普

## 04｜拼贴剪纸地图 Collage Map
- 层级丰富、撕纸边、主视觉冲击力强
- 适合视频包装主视觉

## 05｜丝网印刷地图 Screenprint Map
- 高对比、颗粒、少色
- 适合资源、矿产、历史工业主题

## 06｜科技 HUD 地图 Tech HUD Map
- 扫描、细线、界面感
- 适合卫星、航天、芯片、AI

## 常见任务映射

- 标出爪哇岛 → 区域高亮型 / 纪录片地图
- 太平洋、印度洋、大洋洲色块提取 → 区域高亮型 / 透明背景资产
- 埃及产业地图 → 信息地图型 / 纪录片地图 or 财经信息地图
- 印尼资源流向 → 路线型 + 信息地图型
- 火箭发射/轨道示意 → 路线型 / 科技 HUD 地图
